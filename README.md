# MyTimer

SwiftUIで作成したポモドーロタイマーです。元のピンクを基調としたデザインを残しながら、実用性とコードの読みやすさを改善しました。

## 主な機能

- 25分の集中と5分の休憩
- 集中4回ごとの長い休憩
- 開始、一時停止、再開、リセット、スキップ
- 集中時間・休憩時間・サイクル数の設定
- アプリがバックグラウンドにある間も終了時刻を基準に時間を補正
- 集中完了回数の表示
- タイマー終了時の効果音

## コードで工夫した点

### タイマーを1本に統一

集中用と休憩用に別々のタイマーを持たず、`PomodoroMode`で現在の状態を管理しています。これにより、2つのタイマーが同時に動く問題を防いでいます。

### 時間のずれを防止

1秒ずつ数えるだけではなく、開始時に終了予定時刻を保存します。画面へ戻った際に現在時刻との差を計算するため、バックグラウンド中も時間がずれにくい構成です。

### 画面とロジックを分離

状態の切り替え処理を`PomodoroLogic.swift`へ分けました。画面コードを読みやすくし、ロジックだけを自動テストできるようにしています。

## ファイル構成

- `ContentView.swift`：画面とタイマー操作
- `PomodoroLogic.swift`：集中・休憩の切り替えルール
- `SettingView.swift`：時間とサイクルの設定
- `SoundPlayer.swift`：終了音の再生
- `PomodoroLogicTests.swift`：切り替えルールのテスト

## 動作確認

設定画面には5秒・3秒の動作確認用設定を用意しています。通常利用時の初期値は、集中25分・短い休憩5分・長い休憩15分です。
